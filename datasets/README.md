# Excerpt Datasets Repository

This directory contains evaluation datasets, test ground truths, benchmark manifests, and validation schemas.

---

## Directory Layout

- `gold/`: Human-curated editorial gold sets used for ranking and preference evaluation.
- `benchmarks/`: Benchmark manifest files and ground truth clip intervals.
- `fixtures/`: Media fixture metadata, dummy video headers, and synthetic transcripts.
- `schemas/`: JSON schemas validating candidate windows, render plans, and perception outputs.
