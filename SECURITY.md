## Reporting a Vulnerability

The Excerpt engineering team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose findings.

### Disclosure Protocol
- **DO NOT** report security vulnerabilities via public GitHub issues or discussions.
- Please email vulnerability reports to **security@excerpt.dev** (or contact the repository maintainers directly).
- Include the following details in your report:
  1. Description of the vulnerability and attack vector.
  2. Step-by-step reproduction instructions or proof-of-concept.
  3. Affected components (e.g. API endpoints, media ingestion, worker pipelines).
  4. Potential impact.

### Response Timeline
- **Initial Acknowledgment**: Within 24 hours.
- **Triage & Severity Assessment**: Within 72 hours.
- **Fix & Disclosure Coordination**: We will work with you to release a patch before public disclosure.
