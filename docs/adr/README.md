## Standard Template

Each ADR contains:
- **Title**: Descriptive name prefixed with `ADR-XXX`.
- **Status**: `PROPOSED` | `ACCEPTED` | `DEPRECATED` | `SUPERSEDED`.
- **Context**: The problem, constraints, and baseline evidence.
- **Decision**: The clear, unambiguous technical direction chosen.
- **Alternatives Considered**: Other viable paths and why they were rejected.
- **Consequences**: Positive, neutral, and negative operational impacts.
